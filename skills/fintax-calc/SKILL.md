# 税额试算、原始账单体检与三段资金链核销工作流

纪律：**所有账单汇总、税额、临界点与差额勾稽必须来自 `fintax_parse_statement` 或 `fintax_calc` 工具，严禁模型自行读取几千行 CSV 心算累加。**

## 步骤

0. **若用户提供了原始结算账单、第三方结汇流水或国内对公银行回单（Amazon[含 FR/IT/ES 本地化表头、SE/PL/BE/TR/AE/SA/BR/IN/IE 站点与 2027 FBA 新费用] / TikTok Shop / Temu / 速卖通 AliExpress / Shopee / Shopify / PayPal / Stripe / SHEIN / Walmart / Lazada + 万里汇 WorldFirst / 派安盈 Payoneer / 空中云汇 Airwallex / 连连国际 LianLian / PingPong / 寻汇 SUNRATE + 国内对公银行电子回单 `.csv`/`.tsv`/`.txt`/`.xlsx`/`.zip`，或免文件演示 `demo:v9` / `demo:v8` / `demo:all` / `demo:v7` / `demo:wallets` / `demo:full`）**：
   - **优先直接调用 `fintax_parse_statement`**：单文件或 `.zip` 传 `file_path`，多月/多站点、结汇流水与银行回单批量合并传 `file_paths`；单币种汇率传 `fx_rate_to_cny`，多币种合并对账传 `fx_rates`（如 `{"USD": 7.24, "EUR": 7.82, "MYR": 1.62}`）及 `declared_vat_sales_cny`；需要留存或发给团队审阅时传 `export_report_path: "auto"`（可打印 `.html`）、`"auto.md"` 或 `"auto.csv"`（全量异常排雷清单 CSV）；
   - 输出平台报送、财务会计、增值税与出口、企业所得税四层数据，单列完整三段资金链核销（**① 平台放款 → ② 结汇通道入账 → ③ 国内对公银行回单 5 键实收核销**）。结汇流水与银行回单均绝不重复计入销售收入；一/二段与二/三段均严守 **fail-closed 5 键精确匹配**（主体+对公账号/尾号+账期+参考号+币种金额），缺强凭证的参考级配对独立单列在 `candidateMatches` / `stage3CandidateMatches`（待财务核对电子回单人工确认，绝不污染法定核销）；Stage 3 单列银行扣费、结汇汇损与在途未核销差额。若检出 **P0 优先核查项**（全托管供货混表、提现至个人私户或非对公银行回单），申报前先提示剥离或整改。
   - 如用户核对 **2026 全年 Q1–Q4 汇总与 `2027-01-31` 全球三地交卷自检**（中国 810 号令 Q4 与全年四层合拢、欧盟 DAC7 `€2,000`/30 笔、美国 IRS 1099-K 联邦 `$20,000` 且 `>200` 笔双门槛 + 州级更低门槛），指引其在工作台「年度汇算」按单一主体核验（严禁跨主体混算申报，待认领归档须先一键认领）。

1. **明确口径并选 `fintax_calc` 场景（14 大确定性引擎）**：
   - **平台涉税报送、入账与申报核对** → `platform_tax_reconcile`。平台报送（或账单参考销售额）减实际申报销售额，正数表示前者较高。资金桥接独立列示，实际放款减理论放款，正数表示实际多收。
   - **欧盟 ≤€150 低值包裹 €3+€2 与 PID 反推售价** → `eu_low_value_parcel`。按欧委会 `2026-10-05` 指引第 3 节精确测算 **`€3/项` 临时关税 + `€2/项` 退货不退处理费**（均按包裹内申报的不同商品项/税则项 `hsLineCount` 计收，IOSS 均不代收）、退货沉没成本、PID 含税抽佣额外侵蚀、向上取分保毛利最低可执行售价（反推后强制复核 ≤€150 门槛，超限标记不可行阻断），以及「同箱混装直邮 vs 同购物篮按项拆包直邮 vs 简化单税则 SKU 组合 vs 欧盟海外仓（含退货回收率差盈亏线）」方案对比。
   - **美线 Type 11 直邮 vs 9810 海外仓 DDP 与 IEEPA/FIOR** → `us_t86_vs_9810_ddp`。先判 Type 11 商业非正式进口 **`$2,500` 完税价资格**（超过 `$2,500` 标 `type11Eligible: false` 并要求改走 Type 01 正式报关），再对比单件全链路毛利及月销量利差，支持 `2027-01-15` Amazon US FBA 涨价 `+$0.19` 全盘平均敏感度假设（可用 `fba2027DeltaUsd` 自定义覆盖）；IEEPA/CAPE 退税严格 fail-closed（禁止单端日期互填，须显式指定 `tariffProgram: 'IEEPA'` 且完整起止期或独立 `entryDate` 落在 `2025-02-01` 至 `2026-02-23`［CBP 美东 `2026-02-24 00:00` 停收，CSMS `#67834313`］，逐申报行核实税种、入境/出库日、实缴与清算状态；`Section301`/`Section232`/`Section122`、超期、跨期、缺任一端日期或未指定税种一律归零拦截）；`aceAchBound === false` 触发 **P0 ACE ACH Hold**；并附 **`2027-01-05` CBP FIOR（`91 FR 69977`）+ `CTPAT-validated`** 硬熔断红线（本土 IOR 须位于美国且依法在美设立并满足 ≥51% 美籍/绿卡实益所有与控制，替代资产严格限于持续直接持有的无负担美国不动产且净值取 `$20M` 与上年申报进口货值孰高；`§111.29` 报关行核验延期须申请获准、最晚 `2027-05-06`，不推迟 FIOR 熔断）。
   - **50 万 FBA 有票+无票混合采购拆单比选** → `fba_mixed_procurement_split`。量化对比「硬混一票（A1 视同内销征税+附加税，分列当期应交增值税、期末留抵进项税额［不直接计为经营亏损］与税前损益 / A2 免税不退）」vs「有票 0110 退税 + 无票 9810/9610/1039/合规代理拆单」vs「无票加点补票全走 0110」净收益差额、临界加点率 `g*` 及 2025#17 代理出口实名穿透与 9810 次年 4 月核算期边界。
   - **出口退税取消/下调与电池消费税双税毛利冲击测算** → `export_rebate_cancel_impact`。对比原退税率 vs 取消退税（按 2026#11 第七条视同内销征税，或免税不退对照）毛利断崖及保毛利需涨价幅度；分别核算国内生产环节应纳消费税、购价已含消费税与本批实际可退免额（`exportConsumptionTaxExempt=false` 时未退免消费税真实扣减新旧毛利并计入保毛利 FOB；未确认国标+有效 CMA 报告时主口径按法定 4% 测算，2% 降为条件参考值；明确成品充电宝/成套储能不在电池消费税征税范围）。
   - **供应商开票加点「拿专票退税 vs 合规无票免税」比选** → `export_invoice_breakeven`（精算盈亏临界加点率 g* 与企业所得税联动净利对比）
   - **2026 年第 16 号公告跨境电商出口退运免税资格与省税测算** → `cbec_return_duty_exempt`。核验 2026–2027 申报的 9610/9710/9810/1210 批次、6 个月期限、原状非食品、退税缴回证明及 1210 出区离境起算与退回境内区外。
   - **生产企业出口“免、抵、退”税测算（工贸一体/工厂卖家）** → `export_rebate_manufacturer`（五步法精算征退差转成本、应退税额、免抵税额与附加税计征预警）
   - **严格 >500 万一般纳税人登记临界与进项抵扣拐点测算** → `vat_taxpayer_threshold`。使用连续不超过 12 个月或 4 个季度的累计应征增值税销售额（**严格超过 500 万元**触发强制登记），月 10 万/季 30 万起征点等于起征点时全额计税。
   - **外贸企业出口免退税（购进货物出口，有进项专票）** → `export_rebate`
   - **综试区零售出口核定企业所得税与 300 万超崖跳变** → `cbec_assessed_cit`。4% 应税所得率须经主管税务机关鉴定；小型微利 5% 优惠截至 2027-12-31，输出 300 万超崖跳变对照与 9810 次年 4 月核算期未售冲减提示。
   - **年终奖个税（单独计税 vs 并入综合所得双轨比选）** → `annual_bonus_iit`（含 6 档多发一元陷阱与双轨节税推荐）。
   - **跨境电商零售进口（保税/直购）** → `cross_border_import`
   - **国内销售增值税/价税分离** → `vat`
   - 场景不在支持范围时，说明局限并列出公式。
2. **核对政策参数**：若用户已配置 IMA 知识库，调用 `ima_search` / `ima_browse`（或在工作台使用 IMA 轻检索侧抽屉查看 ≤160 字只读摘要线索后在对话中核对原文）核对现行税率、商品代码退税率与核定条件。未配置 IMA 或检索无结果时，使用默认参数但**显著标注"参数未经知识库核对，按默认口径试算"**。
3. **调用工具**：调用 `fintax_calc`，比例与税率均传 `0~1` 小数（如加点 8% 传 `0.08`，13% 税率传 `0.13`）。
4. **呈现结果**：
   - 展示工具返回的完整分步计算与勾稽过程；
   - 原样保留风险预警（净额法佣金冲收入、欧盟 `€3/项+€2/项` 按申报项计收且处理费退货不退与反推超 €150 阻断、美线 Type 11 `$2,500` 资格门槛、IEEPA 严拒 301/232/122 与单端日期互填及 `2026-02-24` 美东零时停收时点、`ACE ACH Hold` 与 `2027-01-05` FIOR+`CTPAT-validated`［无负担美国不动产替代条件与 `§111.29` 须申请获准延期］、FBA 混合采购分单红线与期末留抵单列、退税取消视同内销征税与消费税出口开关/CMA 报告门禁、成品充电宝豁免、小型微利 300 万超崖与 9810 次年 4 月核算期、严格 >500 万登记条件、退运专项资格、免抵税额计提附加税、2026#11 第六/七条区分、年终奖 6 盲区）；
   - 引用 `policyRefs` 文号并附声明：试算结果用于对账、测算与风险排查，不构成正式纳税申报依据。
