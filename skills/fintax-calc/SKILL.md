# 税额试算工作流

纪律：**所有数字来自 `fintax_calc` 工具，禁止自己心算后直接报结果。**

## 步骤

1. **明确口径并选场景**：确认业务场景后选择对应 scenario：
   - 跨境电商零售进口（保税/直购）→ `cross_border_import`
   - 国内销售增值税/价税分离 → `vat`
   - 年终奖个税（单独计税）→ `annual_bonus_iit`
   - 外贸企业出口退税（购进货物出口，有进项专票）→ `export_rebate`
   - 综试区零售出口企业所得税（无票免税+核定征收）→ `cbec_assessed_cit`
   - 场景不在支持范围（如生产企业免抵退、行邮税、综合所得汇算）时，说明局限并给出公式让用户自行核算或等待插件更新。
2. **核对政策参数**：调用 `ima_list_kbs` + `ima_browse`/`ima_search` 检索现行税率、限值、退税率（商品代码）、核定条件。知识库无凭证或无结果时，用默认参数但**在结果中显著标注"参数未经知识库核对，按默认口径试算"**。出口退税率尤其要核对商品代码——默认退税率=适用税率只是缺省口径。
3. **调用工具**：`fintax_calc`，scenario 与 params 按工具说明传参；税率传 0~1 小数。
4. **呈现结果**：
   - 展示工具返回的完整计算步骤；
   - 标明应纳税额/应退税额、实际税负率；
   - 超限预警、临界点陷阱、9810 口径预警、参数未核对警示原样保留；
   - 引用工具返回的 policyRefs 政策文号（注明"引用前核对现行有效性"）；
   - 附声明：试算不构成申报依据，正式申报以主管税务机关口径为准。
5. **敏感性提示**（可选）：金额接近限值/档位临界点时，提示跨档后的税负变化，可用不同参数再算一次对比；年终奖落在陷阱区间时建议调整发放方案。

## 禁止事项

- 绕过工具直接输出计算结果。
- 把默认政策参数说成"现行规定"而不加核对说明。
- 对工具返回的警告视而不见。
